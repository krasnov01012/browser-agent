# Референсы — ссылки и что в них смотреть

Живое сравнение из облачного окружения было невозможно (сеть блокировала домены), поэтому ссылки
даны по памяти — откройте и проверьте, что адреса актуальны. Копировать не нужно: берём принципы.

| Референс | Ссылка | Что смотреть |
|---|---|---|
| **Webisoft** | https://webisoft.com | структура главной, нумерованный каталог услуг с активной панелью, меню, CTA в каждой смысловой точке, формулировки услуг |
| **Studio Freight** (теперь **Darkroom Engineering**) | https://studiofreight.com → https://darkroom.engineering | редакционная типографика, крупные заголовки по строкам, асимметрия, подача кейсов как отдельных «миров», плавный скролл |
| Lenis (скролл, который мы используем) | https://lenis.darkroom.engineering | как работает сглаженный скролл без перехвата |
| Awwwards — коллекции | https://www.awwwards.com/websites/ | поиск «моментов», которые понравятся: фильтры по Three.js / Scroll / Typography |
| Awwwards — Sites of the Day | https://www.awwwards.com/websites/sites_of_the_day/ | свежие примеры уровня «арт-директор + инженер» |
| Godly | https://godly.website | подборка премиальных лендингов |
| Landing Love / Lapa Ninja | https://land-book.com | структура секций, ритм |
| Three.js examples | https://threejs.org/examples/ | приёмы для 3D-знака: материалы, свет, постобработка |
| Codrops | https://tympanus.net/codrops/ | разборы анимаций и шейдеров с кодом |

Когда будете докидывать понравившиеся моменты — присылайте ссылку + одной фразой, что именно
(анимация меню, переход между секциями, курсор…). Я оформлю как отдельный пункт в `OPEN_QUESTIONS.md`,
прикину стоимость по производительности и внесу, не копируя.
