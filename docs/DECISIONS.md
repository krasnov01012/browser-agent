# Решения реализации (ADR)

Решения, принятые при сборке сайта. Это **не** решения владельца по бренду (они — в
`docs/brief/00_DECISIONS.md`); всё ниже можно пересмотреть, если владелец не согласен.

## ADR-001 — Astro (статическая сборка) вместо Next.js
**Контекст.** Маркетинговый сайт с двумя языками, тяжёлой графикой в одном месте (Hero) и
формами, бэкенд для которых ещё не выбран.
**Решение.** Astro 7, `output: static`, маршруты `src/pages/[lang]/…` через `getStaticPaths`.
**Почему.** Ноль JS по умолчанию — быстрый первый экран, на котором сайт и оценивают; острова
грузят только нужное (Three.js — только там, где есть сцена K); честный HTML для SEO и
hreflang; деплой куда угодно (любой статический хостинг/CDN). Бэкенд заявок подключается
отдельным сервисом/функцией, контракт уже зафиксирован (`src/lib/leads.ts`).
**Цена.** Требуется Node ≥ 22.23.4 (`.nvmrc` = 24 LTS).

## ADR-002 — Без CSS-фреймворка
Собственные токены (`tokens.css`) + scoped-стили компонентов. Tailwind-утилиты ведут к
узнаваемому «шаблонному» виду и размывают дизайн-систему; здесь каждая секция имеет свою
логику раскладки, а общие вещи — в токенах и примитивах (`.btn`, `.label`, `.eyebrow`, `.line-mask`).

## ADR-003 — Движение без GSAP
CSS-переходы, `@keyframes`, **scroll-driven animations** (`animation-timeline: view()`) для
моста и трека процесса — с `@supports`-фолбэком в статичное состояние; IntersectionObserver
для появлений; Lenis — только сглаживание колеса, без перехвата и pinning. Всё декоративное —
под классом `.motion` (нет `prefers-reduced-motion`), циклы — только пока сцена видна.

## ADR-004 — 3D-знак K: геометрия из `geometry.json`, а не прямая загрузка GLB
**Аудит `architectural-k.glb`.** glTF 2.0 (trimesh), 11 КБ: `world` → `K_UPPER_BEAM`,
`K_LOWER_BEAM`, `K_STEM`, `K_SIGNAL_UPPER`, `K_SIGNAL_LOWER`, `K_SIGNAL_JOINT`; 6 PBR-материалов
(сатиновый титан/сталь, коралловая эмиссия); **0 анимаций**. Каждая деталь — призма из 12 вершин
**без нормалей и UV**, без фасок; швы — плоские четырёхугольники; балки лежат в одной глубине
(±0.13) и пересекаются в узле → мерцание (z-fighting).
**Решение.** Строить те же контуры процедурно: `ExtrudeGeometry` по точкам из `geometry.json`
(то же отображение `x' = (x−500)/165`, `y' = (500−y)/165`, та же толщина 0.30/0.26), с фасками
`bevelOffset = −bevelSize` — силуэт совпадает с v02 точно. Верхняя балка смещена на 0.022 вглубь
(в узле сверху лежит нижняя, как в SVG v02). Материал — `MeshPhysicalMaterial` (металл,
анизотропия вдоль детали, процедурная карта «шлифовки», clearcoat). Свет — студийное окружение,
собранное в PMREM из софтбоксов + одна узкая коралловая полоса для тёплых рефлексов; узел —
коралловая точка, шеврон из SVG v02, мягкий ореол и точечный свет. Никаких внешних HDR и текстур.
**Итог.** Знак та же K v02, но с фасками и материалом ближе к утверждённому референсу. Это
**не** финальный мастер: пропорции/фаски/металл можно уточнять, когда придёт финальная модель —
тогда сцена может перейти на загрузку оптимизированного GLB с теми же именами узлов.

## ADR-005 — Хореография и fallback K
Чертёж построения (SVG в том же пространстве 1000×1000) рисуется сразу; 3D подгружается
динамическим `import()`. Сборка ≈7 с: опора → верхняя балка → нижняя → загорается узел, швы
прочерчиваются от узла → блик по металлу и выход во фронтальный ракурс. Ранний скролл/клавиша →
досрочное завершение за ~0.7 с. Рендер по требованию: кадры рисуются только пока что-то движется,
сцена вне экрана/вкладка скрыта — пауза. Fallback на SVG v02: нет WebGL, ошибка, потеря контекста,
6 с без первого кадра. Reduced-motion — статичный кадр в покое. Без JS — SVG.

## ADR-006 — Contact + Project Architect в одной секции `[PROPOSED]`
Две формы с одинаковыми полями связи и одним endpoint превращены в один «пульт» с двумя
режимами (вкладки): короткая заявка и бриф в 4 шага. Меньше дублей и длины страницы, а
`#architect` по-прежнему ведёт прямо в бриф. Требует подтверждения владельца.

## ADR-007 — Режим ревью `?review`
Статусы из реестра (`draft`, `proposed`, `placeholder`, `verify`, `reserved`) размечены
атрибутом `data-status`. С `?review` они подсвечиваются, а зарезервированные места (например,
003 Engineering Lab) становятся видимыми. Владелец видит, что утверждено, а что — нет, прямо на сайте.

## ADR-008 — Шрифты
Geist Variable и IBM Plex Mono через Fontsource (OFL 1.1), самохостинг — без запросов к Google
Fonts (приватность, скорость). Preload основного начертания под язык страницы.

## ADR-009 — Язык по умолчанию
Не решён. `/` выбирает язык по `navigator.languages` (русский и языки СНГ → `/ru/`, иначе `/en/`);
без JS — две ссылки. При выборе хостинга заменить на серверный редирект по `Accept-Language`.

## ADR-010 — Переходы между страницами без SPA-роутера
`@view-transition { navigation: auto }` — нативные cross-document View Transitions (Chromium,
Safari 18.2+): мягкая смена страниц без клиентского роутера и без переинициализации скриптов.
Шапка помечена `view-transition-name` и не «моргает». В остальных браузерах — обычная навигация.
Под `prefers-reduced-motion` отключено.

## ADR-011 — Ассеты из настоящей сцены
Постер K (fallback без WebGL), OG-картинка и apple-touch-icon рендерятся скриптом из той же
Three.js-сцены (`npm run assets:k`), а не рисуются отдельно — знак везде один и тот же.

## ADR-012 — Превью для владельца — приватный артефакт claude.ai
До выбора хостинга владелец смотрит сайт через приватный артефакт. Сборка Astro использует
абсолютные пути, а артефакт отдаёт файлы не из корня домена и резервирует имена с `_`, поэтому
`scripts/stage-artifact.py` готовит отдельную копию: относительные ссылки, `_astro/` → `assets/`,
страницы как явные `index.html`, патч базового пути modulepreload Vite. Исходная сборка и
репозиторий не меняются. Ограничения превью: не работают `?review` и `?source=` (query-строки
не передаются). Процедура — `docs/HANDOFF.md` §7.
