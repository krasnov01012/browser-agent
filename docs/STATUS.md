# Статус — итерация 1 (ночь 28→29.10.2026)

Ветка `krasnoff-site`. Предварительная сборка для ревью владельца — **не для публикации**
(тексты — черновики, медиа — подписанные иллюстрации, заявки не подключены; `robots.txt`
закрывает индексацию).

## Что сделано

### Страницы (RU и EN)
| Маршрут | Содержание |
|---|---|
| `/` | выбор языка по браузеру (без JS — две ссылки) |

### Главная
- **Hero** — Balanced Composition; 3D Architectural K из `geometry.json` v02 (фаски, шлифованный
  металл, коралловый узел и швы, студийные отражения); чертёж построения с реальными размерами
  (117 · 750 · 47.9°); сборка ~7 с не блокирует контент; наклон за курсором ±4–5°; уход вглубь
  при скролле; ранний скролл досрочно завершает сборку; рендер только по требованию и пауза вне
  экрана; fallback — пререндер 3D-знака (WebP, 36 КБ). Внизу — пять направлений-ссылок в каталог.
- **Услуги** — каталог из 5 строк + тёмная панель с технической SVG-схемой, составом и CTA,
  передающим контекст в форму; hover/клик/клавиатура; на мобильных — аккордеон под строкой.
- **Мост** «Не просто идеи. / Работающие системы.» — графитовая плоскость раскрывается по скроллу
  (CSS scroll-driven animations).
- **Работы** — Seshat (широкая сцена во всю ширину, «время», 4 недели и сигнал «сейчас»)
  и MARK (асимметричная панель, поток строк через гейты, потоки данных с края страницы).
  Обе схемы подписаны как иллюстрация/синтетика. 003 Engineering Lab — зарезервировано (`?review`).
- **О студии / Подход**, **Процесс** (5 этапов, форматы работы, политика цен без цен).
- **Приём заявок** — «пульт» из двух режимов: короткая заявка и бриф проекта в 4 шага; общий
  контракт `src/lib/leads.ts`, валидация по каналу, idempotency-key, honeypot, честные состояния.
- **Шапка/подвал** — гибридная навигация, мобильное меню (Esc, inert-фон, фокус), язык с
  сохранением маршрута, OG-картинка из настоящего 3D-рендера, favicon и apple-touch-icon.
- **Режим ревью** — `?review` подсвечивает `draft / proposed / placeholder / verify / reserved`.

### Проверки (автоматизированы в `scripts/`)
- `astro check` — 0 ошибок, 0 предупреждений.
- `qa:interact` — 23/23: каталог, контекст CTA → форма, ошибки пустой формы, «приём не подключён»
  без endpoint, валидация email/Telegram, мастер брифа и сводка, отсутствие цен, язык, вкладки
  Seshat, конвейер MARK с клавиатуры (←/→/Home), мобильное меню + Escape + inert, аккордеон,
  без JS — все этапы MARK читаемы и виден постер K.
- `qa:shots` — 1440 / 1280 / 768 / 390: горизонтальное переполнение 0, ошибок консоли 0, оба языка;
  reduced-motion — статичный кадр K, без анимаций.
- Контраст (WCAG): все пары текст/фон ≥ 4.5:1 (производные оттенки подобраны под AA).
- Вес: HTML главной ≈ 16 КБ gzip; общий JS ≈ 8 КБ gzip; Three.js-сцена ≈ 143 КБ gzip — лениво,
  только на главной; шрифты — self-hosted, preload под язык.

## Как интерпретированы референсы (art-director check)
- **От Webisoft (структура):** понятная IA главной, пронумерованная таксономия услуг с активной
  панелью, сканируемый процесс, CTA в каждой смысловой точке, уверенная навигация с индексами.
- **От Studio Freight (подача):** крупная редакционная типографика с построчным появлением,
  асимметрия, работа с пустотой, кейсы как отдельные «миры» со своим ритмом, переходы с намерением
  (мост ivory → графит).
- **Своё у Krasnoff:** Architectural K как физический объект, чертёж построения с реальными
  размерами v02, коралловый «шов» как сквозной мотив (линии активных строк, узлы на пересечениях,
  сигнальная точка в заголовках), технические моно-подписи, честная маркировка статусов.
- **Против шаблона:** ни одной сетки одинаковых карточек с иконками, ни одного «пятна»/глассморфизма,
  ни одной метрики-счётчика; у каждой секции своя логика раскладки.

## Известные ограничения
- WebGL проверялся в headless Chromium (SwiftShader). Нужна проверка на реальных устройствах
  (iOS Safari, Android, слабые ноутбуки) — особенно свет/металл и FPS.
- Scroll-driven анимации (мост, трек процесса) работают в Chromium; в остальных браузерах —
  корректное статичное состояние.
- Скринридеры вручную не проверялись (семантика и ARIA — по стандарту, автоматические проверки пройдены).
- `sitemap.xml` не генерируется до выбора домена (`SITE_URL`).
