# KRASNOFF DEVELOPMENT — ARCHITECTURAL K / V02

Версия 0.2. Внесена геометрическая коррекция после замечания, что предыдущая концепция визуально читалась как K/N. Базовый знак теперь содержит непрерывную вертикальную опору и **две самостоятельные диагональные балки**, образующие латинскую **K**.

## Состав

- `APPROVED_VISUAL_REFERENCE.png` — утверждённый художественный референс K и стиля (не векторный исходник).
- `architectural-k-primary.svg` — 2D-версия с градиентами и коралловыми швами, прозрачный фон.
- `architectural-k-monochrome.svg` — однотонная версия для применения на тёмном фоне.
- `architectural-k-on-graphite.svg/.png` — просмотр знака на фирменном графите.
- `architectural-k-blueprint.svg/.png` — точная схема построения версии 0.2.
- `krasnoff-lockup.svg/.png` — рабочая типографическая композиция KRASNOFF DEVELOPMENT.
- `architectural-k.glb` — реальная 3D-сцена из трёх основных геометрических деталей и световых элементов, которые можно анимировать отдельно.
- `assembly-preview.html` — HTML/Three.js прототип сборки.
- `geometry.json` — точные опорные координаты 2D/3D.

## Открытие прототипа

Распакуйте архив и запустите локальный HTTP-сервер в его каталоге:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/assembly-preview.html`. Для работы требуется интернет (Three.js загружается через CDN), поддержка WebGL и доступ к локальному .glb.

## Статус и ограничения

**Это не финальный мастер бренда.** Это исправленная инженерная версия K с общей для SVG и GLB геометрией. Металлические материалы, фаски, художественный свет и типографика пока упрощены по сравнению с утверждённым рендером. Содержимое раннего архива v01 **не используется**. Для финала нужны утверждение пропорций знака на реальных размерах, доработка объёмных фасок, полноценный свет/рендер и финальная типографика.
