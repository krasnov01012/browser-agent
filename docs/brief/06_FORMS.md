# Заявки: короткая форма, Project Architect, требования к бэкенду

## Утверждено
Одна универсальная система для RU/EN. Посетитель выбирает канал ответа **Telegram или Email**.
Project Architect — необязательная альтернатива короткой форме. **Нет** калькулятора и обязательного бюджета.

## Реализовано на фронтенде
- Поля: имя, канал ответа, контакт (валидация зависит от канала), описание, согласие (текст — черновик).
- Контекст CTA (услуга/кейс/hero) — только несекретный `source`/`intent`, удаляемый посетителем.
- Project Architect: 4 шага (тип → возможности по типу → контекст → редактируемая сводка + те же поля).
  Шаги можно пропускать, возвращаться по рельсу; данные только в памяти страницы.
- Отправка: `POST PUBLIC_LEADS_ENDPOINT`, JSON по контракту `src/lib/leads.ts`, заголовок
  `Idempotency-Key` (повтор после ошибки не создаёт дубль), сигналы антиспама (honeypot, время заполнения)
  передаются серверу, клиент сам ничего не «отбраковывает».
- Состояния: «принято и сохранено» **только** после 2xx с `accepted: true`; ошибка сохраняет текст в
  форме; без endpoint — честное «приём не подключён».

## Нужно спроектировать до запуска (не реализовано)
- Бэкенд и хостинг (не выбраны), БД, защищённая админка, уведомления администратору в Telegram и
  резервно на email, очередь/повторы, наблюдаемость, без двойных лидов.
- Ответ 422 с `fields: string[]` для серверной валидации; rate-limit, антибот без блокировки людей.
- Согласие и политика под фактического оператора; сроки хранения, доступ, удаление.
- Telegram: бот не может написать первым по `@username`. После сохранения лида — кнопка открыть бота
  со случайным одноразовым токеном привязки (не текст заявки, не персональные данные).
- Вложения — только если будут защищены (размер, тип, антивирус).
- Возможная запись: `id, created_at, locale, source, request_kind, reply_channel, reply_value, name,
  description, brief_json, consent_version, status, admin_notes, notification_state`.
- Статусы (не CRM): New → Contacted → Qualified → Proposal → Won / Lost/Archived.

## Никогда
Публичные цены; обещания «ответим за 15 минут»; запрос секретов клиента в форме; открытый
просматриваемый endpoint лидов; текст заявки или ПДн в URL.
