## 1. Быстрый старт новой сессии

1. Прочитай этот файл целиком, затем `CLAUDE.md`.
2. `git checkout krasnoff-site` — вся работа в этой ветке; `main` всё ещё содержит старый
   проект browser-agent (не трогали, ждём решения владельца о слиянии).
3. Node ≥ 22.23.4 (`.nvmrc` = 24): `node -v`. Если старее — см. §6.1.
4. `npm install && npm run build && npm run qa` — должно быть зелёным (qa:fit + 23/23 qa:interact).
   Для QA нужен Playwright — см. §6.2.
5. Спроси владельца, что из `docs/OPEN_QUESTIONS.md` он уже решил, — и только потом меняй тексты,
   шрифты, структуру.

## 2. Владелец и как с ним работать

- Общение **на русском**. Владелец — основатель студии Krasnoff Development (сейчас ведёт её один,
  студия подаётся институционально, без выдуманной команды).

  присылают скриншоты и живое превью.
- **Главный приоритет — визуал, «отточенный до идеала», и технологичность**: «сайт разработчика
  оценивают с первой секунды, как на него зайдут».
- Явное правило: **то, что ещё не обсуждалось, — не придумывать как утверждённое**, оставлять
  место и выносить на обсуждение (`docs/OPEN_QUESTIONS.md`, режим `?review`).
- Референсы, выбранные владельцем: **Webisoft** (структура, навигация, услуги, конверсия) и
  **Studio Freight** (редакционная подача, типографика, сторителлинг кейсов, motion). Не копировать.
- Последний вопрос владельца был «похоже ли на референсы» — ответ и самооценка в §8.
- Владелец, вероятно, на Windows (старый проект в этом репо был под PowerShell/cp1251).

## 6. Окружение и собранные грабли

### 6.1 Node
Astro 7.4.4 требует Node ≥ 22.23.4. В облачном контейнере был 22.22 → скачан Node 24 LTS в
папку сессии и добавлен в `PATH` (`curl -O https://nodejs.org/dist/v24.x/node-…-linux-x64.tar.xz`).
Локально: `nvm use` (`.nvmrc` = 24) или установщик Node 24 LTS.

### 6.2 Playwright (QA-скрипты)
Скрипты `scripts/qa-*.mjs` и `render-k-assets.mjs` подключают Playwright через `createRequire`
и **не** указан в `package.json` (в облаке он предустановлен глобально). Локально:
`npm i -D playwright && npx playwright install chromium`. WebGL в headless запускается с
`--use-angle=swiftshader --enable-unsafe-swiftshader --ignore-gpu-blocklist` (уже в скриптах).
Владельцу предлагалось добавить Playwright в devDependencies — решения пока нет.

### 6.3 Грабли (не наступать снова)
- `astro preview` в Astro 7 — **фоновый демон** («already running»); останавливать
  `npx astro preview stop`. QA-скрипты поэтому используют свой `scripts/serve-dist.mjs`.
- `pkill -f "astro preview"` убивает и собственный shell (шаблон совпадает с его командой).
- Chromium `fullPage`-скриншот ломается на высоте > ~8000 px (повторяет верх) — `qa-screenshots`
  снимает кадрами по высоте экрана.
- `body { overflow-x: clip }` прячет вылезающий текст от `scrollWidth` — для этого есть `qa:fit`.
- Scoped-стили Astro не достают элементы дочернего компонента (например, `<h1>` из `Lines`
  внутри `Hero`) — нужен `:global(...)`.
- Кегль крупных заголовков считается от ширины колонки (`cqi`); `.line-mask` по Y обрезает,
  по X — нет (иначе режутся длинные слова), с запасом под Ё/Й.
- Неактивные вкладки скрыты атрибутом `data-tab-hidden` (CSS `.js [data-tab-hidden]`), а не
  `hidden` — без JS видно всё, с JS нет вспышки.
- Эмиссия в Three.js: цвет × > 1 с `toneMapped: false` выбеливает коралл в персиковый; точка
  узла должна лежать **перед** аддитивным ореолом.
- Блик по металлу: ограничен поворотом окружения (−0.5 → 0.1), иначе опора пересвечивается в белое.
- Минификатор CSS превращает `stroke-dashoffset: 1` в `1px` — с `pathLength="1"` это корректно.
- Сеть облачного окружения **блокирует webisoft.com и studiofreight.com** — чтобы сравнить с
  референсами, владелец должен добавить домены в Allowed domains (настройки окружения → Network access).
- Артефакты claude.ai: имена файлов/папок с `_` зарезервированы; query-строки (`?review`,
  `?source=`) между страницами превью не передаются.

## 8. Самооценка дизайна и ответ «похоже ли на референсы»

Копией не выглядит — так и задумано (бриф запрещает клонирование). Взят принцип: структура
Webisoft + подача Studio Freight; по характеру — строже и «инженернее» обоих.

| Критерий рубрики (0–5) | Оценка | Комментарий |
|---|---|---|
| Уникальность бренда | 4 | K-сборка по чертежу, коралловый шов, моно-подписи — своё |
| Типографика | 4 | Geist слишком распространён; авторская гарнитура заголовков дала бы 4.5–5 |
| Композиция секций | 4 / 3.5 | Верх сильный; «О студии» и «Процесс» ближе к хорошему шаблону |
| Знак K | 4 | Металл и узел хороши; до кинематографичного референса не хватает света/глубины |
| Кейсы | 3 | Без реальных записей Seshat/MARK выше не поднять |
| Движение | 4 | Один сильный момент (Hero), дальше сдержанно (бриф против pinning) |
| Адаптив / техника | 4.5 | QA зелёный на 320–1440, CLS 0 |
| Конверсия / честность | 4 | Нет соцдоказательств — и выдумывать нельзя |
| RU/EN | 4 | Тексты — черновики |
