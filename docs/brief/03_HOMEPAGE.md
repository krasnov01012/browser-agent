# Главная — сценарий и арт-дирекция

## Позвоночник (утверждённый ритм + реализованный порядок)
0. **Шапка** — знак и `KRASNOFF / DEVELOPMENT`, Работы, Услуги, О студии, RU/EN, «Обсудить проект».
   Компактная графитовая подложка после прокрутки; прячется при прокрутке вниз; мобильное меню (Esc, фокус).
1. **Hero (тёмный)** — Balanced Composition: заголовок слева (~52%), 3D K справа (~48%) без «карточки».
   Чертёж построения K из реальных координат v02; сборка 6–8 с; затем наклон за курсором ±4–5°;
   при прокрутке знак уходит вглубь. Внизу — пять направлений, ведущих в каталог услуг.
2. **Услуги (светлые)** — каталог из 5 пронумерованных строк + тёмная панель с технической схемой,
   составом и CTA «Обсудить задачу» (передаёт контекст в форму). Mobile — аккордеон.
3. **Мост** — «Не просто идеи. / Работающие системы.»: вторая строка на графитовой плоскости,
   которая раскрывается на всю ширину по скроллу (scroll-driven CSS).
4. **Избранные работы (тёмные)** — 001 Seshat: широкая сцена Deep Wine, «время»; 002 MARK:
   асимметричная панель Deep Ink, потоки данных с края страницы. Не две одинаковые карточки.
   003 Engineering Lab — зарезервировано (видно только в `?review`).
5. **О студии / Подход (светлые)** — кто (без вымышленной команды) и почему (4 принципа).
6. **Процесс (светлый)** — 5 этапов, форматы работы, политика цен без цен.
7. **Приём заявок (тёмный)** — короткая заявка и бриф проекта в одном «пульте» `[PROPOSED]`.
8. **Подвал** — навигация, работы, язык, правовое (политика — заглушка), без выдуманных адресов.

## Hero: требования
- Текст, навигация и CTA доступны с первой миллисекунды; 3D никогда не перекрывает контент лоадером.
- Если посетитель скроллит во время сборки — сборка корректно досрочно завершается (~0.7 с).
- `prefers-reduced-motion` — статичный кадр без сборки и реакции на курсор.
- Нет WebGL / ошибка / потеря контекста / 6 с без кадра — SVG-знак v02.
- K обязана читаться как одна латинская K (не K+N) на любых размерах.

## Знак K v02 — что есть
`design/k-v02/`: primary/monochrome/on-graphite/blueprint SVG, lockup, `architectural-k.glb`,
`geometry.json`. GLB: узлы `K_STEM`, `K_UPPER_BEAM`, `K_LOWER_BEAM`, `K_SIGNAL_UPPER`,
`K_SIGNAL_LOWER`, `K_SIGNAL_JOINT`; 6 материалов; **0 анимаций**. v02 — рабочая геометрическая
интерпретация, не финальный мастер (фаски, металл, свет, типографика lockup — в работе).
Утверждённый художественный референс (PNG) — в приватном хэндоффе, в репозиторий не добавлен.
