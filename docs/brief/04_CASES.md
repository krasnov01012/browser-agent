# Кейсы: Seshat и MARK — факты, границы правды, структура страниц

Оба — **собственные независимые продукты студии**, не заказы. Арт-направления v1.2 утверждены
(см. реестр). Тексты, тайминги, медиа и цифры — черновики до фактчекинга. Страницы кейсов
закрыты `noindex` до проверки фактов и появления реальных записей.

## Seshat — «Время под контролем» (Deep Wine / Time Signal)

**Что это (по описанию владельца, срез `[VERIFY]`):** персональный AI-диспетчер и планировщик.
Интерфейс — Telegram; ядро API-first (Python 3.12, FastAPI, Aiogram 3, PostgreSQL 16,
SQLAlchemy 2 async, Alembic, Docker). Гибридный разбор языка: быстрый детерминированный парсер →
LLM с защищёнными вызовами и резервным провайдером → пошаговая FSM без AI. Календарная арифметика,
RRULE (RFC 5545), часовые пояса/DST, проверки пересечений — детерминированный код. Карточка
подтверждения перед любым изменением, черновики на сервере, журнал изменений и Undo, advisory locks,
watchdog планировщика, деплой с проверенными бэкапами, «аддитивными» миграциями и автооткатом.

**Нельзя выдавать за готовое:** полноценный веб-клиент (SPA в разработке); включённую синхронизацию
Google Calendar (код есть, выключен до публикации политики и верификации OAuth); голосовой ввод;
«Горизонт 3» (долговременная память, глобальные цели).

**Цифры — только после проверки по CI/репозиторию:** число автотестов и период наблюдения доставки
уведомлений из среза владельца. На публичных страницах сейчас **не** выводятся.

**Страница (7 сцен):** 01 Hero (wine) · 02 Задача (ivory): «понимание» vs «исполнение» ·
03 Опыт (тёмная): вкладки Создать / Изменить / Подвести итоги · 04 Архитектура: «Продукт» /
«Инженерия» · 05 Инженерные решения (ivory): надёжность, целостность данных, деплой, тесты ·
06 Статус: работает / в разработке · 07 Следующий кейс + CTA (графит + коралл).

**Медиа (нужно снять):** реальные записи Telegram на демо-профиле — создание рутины, перенос
события, реакция на напоминание, вечерний итог; тизер 8–12 с для главной, ролик ~45 с; постеры;
субтитры при наличии речи.

## MARK — «Сигнал вместо шума» (Deep Ink / Ice Signal)

**Что это (по описанию владельца, `[VERIFY]` по коду):** персональный рабочий AI-агент поиска
вакансий. Источники — HeadHunter API и Habr Career RSS → нормализация → детерминированные фильтры →
LLM-сопоставление с **приватным** карьерным профилем → результат в Telegram.

**Нельзя:** публичный многопользовательский SaaS; автоотклики; продукт для работодателей; заказ
клиента; проценты совпадения, число вакансий/пользователей, «сэкономленное время»; реальный профиль,
фильтры, промпты, переписки, токены. Логотипы HH/Habr — только после проверки условий; текстом можно.

**Страница (7 сцен):** 01 Hero (ink) · 02 Задача (ivory) · 03 Интерактивный конвейер из 5 этапов
(Источники → Единый формат → Явные правила → AI-оценка → Telegram) · 04 «Правила перед AI» (mist) ·
05 Реальный результат — слот под запись · 06 Инженерия и честный статус · 07 Следующий кейс + CTA.

**Медиа (нужно снять):** аудит кода (только чтение), обезличенная запись реального прогона и
сообщений Telegram на демо-аккаунте, тизер 8–12 с, ролик 30–40 с, постеры.

## Общее
- Синтетические схемы всегда подписаны: «СХЕМА · СИНТЕТИКА — НЕ ИНТЕРФЕЙС ПРОДУКТА».
- CTA кейса — «Обсудить похожий проект» → общая форма с `source=seshat_case|mark_case`, `intent=similar_project`.
- Для видео: без звука в автоплее, постер, ленивая загрузка, пауза вне экрана, управление.
